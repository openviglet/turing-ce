Model Catalog

An open, vendor-neutral reference of the models Viglet Turing ES knows about — each tagged with its kind (chat, embedding, rerank, …) plus context window, embedding dimensions and capabilities. Free to consume as a public API.

63 models · 11 vendors · schema v1 · updated 2026-07-20

Public API

Fetch the catalog as JSON (CORS-open). Pin catalog-v1.json for a stable schema; catalog.json tracks the latest.

  • https://turing.viglet.org/models/catalog.json
  • https://turing.viglet.org/models/catalog-v1.json (pinned to v1)
  • https://turing.viglet.org/models/catalog.schema.json (JSON Schema)
curl -s https://turing.viglet.org/models/catalog-v1.json \
  | jq '.vendors | to_entries[].value[] | select(.kind=="EMBEDDING") | .id'
